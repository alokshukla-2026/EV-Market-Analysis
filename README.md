# Electric Vehicle Market Analysis
## Project by Alok Shukla

This project analyzes electric vehicle (EV) technical specifications using Python and data visualization. The analysis focuses on battery capacity, driving range, efficiency, vehicle body type, drivetrain and brand representation.

### Objectives
- Inspect and clean EV specification data.
- Analyze EV brands and body types.
- Study driving-range distribution.
- Explore the relationship between battery capacity and driving range.
- Produce visualizations and summary insights.
- Prepare the data for an interactive Tableau dashboard.

### Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Tableau

### Important Note
This is a specification-analysis project. Brand counts are dataset representation, not actual market share, and listed range is not a guarantee of real-world range.
